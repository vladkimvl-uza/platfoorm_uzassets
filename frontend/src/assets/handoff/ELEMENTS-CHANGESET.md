# UzAssets — применить элементы дизайна (только визуал, без структуры)

> Все 19 новых элементов системы собраны в один файл **`elements.css`** (классы
> `.uza-*`, на токенах `colors_and_type.css`). Применяются **навешиванием классов на
> существующую разметку** — структуру/иерархию DOM менять не нужно.
>
> Эталоны рендера: `preview/elements/*.html` и собранный экран `preview/screens/company-card.html`
> (вкладка Design System → группы **Elements** / **Screens**).

## Как подключить (1 шаг)

```
1. Скопируй elements.css в src/assets/ (рядом с main.css).
2. Подключи ПОСЛЕ colors_and_type.css / main.css (нужны токены --p, --green, …).
   Vite: import '@/assets/colors_and_type.css'; import '@/assets/elements.css';
```

Если токенов в проекте нет — в начале `elements.css` есть fallback-значения, файл
работает автономно.

## Как применять (навесить классы, разметку не трогать)

Каждый класс — чисто косметика. Берёшь существующий блок и добавляешь класс:

| Элемент | Класс(ы) | Куда вешать |
|---|---|---|
| Число разной жирностью | `.uza-num` + `<span class="int/dec/unit">` | KPI-значения |
| Лента согласования | `.uza-tl` › `.uza-tl-ev[.ok/.now]` | история статусов/аудита |
| Поиск / сегмент / чипы | `.uza-search`, `.uza-seg`, `.uza-chip` | панель фильтров |
| Тосты | `.uza-toast[.ok/.warn/.err/.info]` | контейнер уведомлений |
| Хлебные крошки / табы | `.uza-bc`, `.uza-tabs` › `.uza-tab[.on]` | шапки страниц |
| Аватары (секторные) | `.uza-av .md/.lg .mining/.oilgas/…` | компании, исполнители |
| Стек аватаров | `.uza-stack` › `.uza-av` | команда проекта |
| Степпер формы | `.uza-steps` › `.st[.done/.now]` | мастера/формы |
| Документы | `.uza-doc` › `.ft.pdf/.xls/.doc` | списки файлов |
| Пустое состояние | `.uza-empty` | нет данных / поиск |
| Таблица | `.uza-table` | списки компаний/проектов |
| Toggle/checkbox/radio | `.uza-switch/.uza-check/.uza-radio` + `.on` | формы, настройки |
| Модалка подтверждения | `.uza-confirm` | удаление/архив |
| Тултип / поповер | `.uza-tipwrap` › `.uza-tip`/`.uza-pop` | подсказки |
| Бейджи / точки / счётчики | `.uza-badge.<тон>`, `.uza-statusdot`, `.uza-count` | статусы, каунтеры |
| Кольца прогресса | `.uza-ring` | покрытие/рейтинги |
| Стат-плитка | `.uza-tile` | сводные метрики |
| Календарь | `.uza-cal` | дата-пикеры |
| Аккордеон | `.uza-acc-item[.open]` | свёрнутые секции |
| Слайдеры | `.uza-track` › `.fill`/`.knob` | пороги/диапазоны |
| Dropzone / загрузка | `.uza-dz`, `.uza-upload` | загрузка файлов |
| Прогресс-бар | `.uza-bar` › `div[width%]` | строки/таблицы |
| Кнопки | `.uza-btn[.primary/.danger]` | действия |

## Пример (Vue, разметка та же — добавлены классы)

```html
<!-- было -->
<span class="kpi">{{ pct }}%</span>
<!-- стало: визуально число разной жирностью, структура не изменилась -->
<span class="kpi uza-num"><span class="int">{{ whole }}</span><span class="dec">.{{ frac }}</span><span class="unit">%</span></span>
```

```html
<!-- статус-бейдж: меняем только класс -->
<span class="uza-badge green">Принято</span>
<span class="uza-statusdot"><span class="d" style="background:var(--green)"></span>Активный</span>
```

## Правила соответствия системе

- **Без `border-left`-акцентов.** Индикаторы — точка/бейдж/верхняя или боковая вставная
  полоска (см. `handoff/CORE-CHANGESET.md` §1). В `elements.css` left-border нигде нет.
- **Полные слова, без сокращений** в подписях статусов/этапов.
- **Секторные цвета** (mining/oilgas/chem/transport/energy) — единые в аватарах и чипах.
- **Числа** — tnum + разная жирность для денежных/крупных значений.
- **Тёмная тема**: классы используют токены, поэтому подхватят `[data-theme="dark"]`
  автоматически, если внедрена тёмная палитра из `CORE-CHANGESET.md` §3.

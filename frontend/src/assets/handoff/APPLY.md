# APPLY — стартовая инструкция для Claude Code

> Это точка входа. Открой этот репозиторий (`platfoorm_uzassets` / `uzassets-platform-FULL`)
> в **Claude Code**, скопируй файлы дизайн-системы (ниже) в проект и выполняй разделы по
> порядку. Каждый шаг ссылается на подробный changeset с готовыми промптами и списком
> файлов/строк.

## 0. Скопировать файлы дизайн-системы в репозиторий

Из проекта «UzAssets Design System» возьми и положи в `src/assets/`:

- `colors_and_type.css` → `src/assets/colors_and_type.css` (токены: цвета, тип, радиусы, тени, тёмная палитра)
- `elements.css` → `src/assets/elements.css` (19 переиспользуемых `.uza-*` классов)

Подключи в entrypoint **после** `main.css`:
```js
import '@/assets/colors_and_type.css';
import '@/assets/elements.css';
```

И положи рядом 4 changeset-документа (как справку): `CORE-CHANGESET.md`,
`ELEMENTS-CHANGESET.md`, `REDESIGN-CHANGESET.md`, `PROPOSALS-CHANGESET.md`.

## Порядок применения

### Шаг 1 — Базовая система → `CORE-CHANGESET.md`
Токены (сверка + `--acc-operational`/`--acc-transform`) → миграция всех цветных
`border-left` в боковую вставную полоску (`uza-side-stripe.css`, полный инвентарь файлов
внутри) → donut'ы к тонкому кольцу → тёмная тема `[data-theme="dark"]` + переключатель в топбаре.

**Стартовый промпт для Claude Code:**
```
Прочитай CORE-CHANGESET.md и примени разделы 0→1→2→3 по порядку. После каждого раздела
покажи diff и прогоняй npm run lint + сборку. Структуру компонентов и их API НЕ меняй —
только стили/классы/токены. Не трогай структурные хайрлайны border-left:0.5–1px (список
исключений в §1).
```

### Шаг 2 — Элементы → `ELEMENTS-CHANGESET.md`
Навесить `.uza-*` классы на существующую разметку (таблица «элемент → класс → куда вешать»).
Разметку **не реструктурировать** — только добавлять классы.

```
Прочитай ELEMENTS-CHANGESET.md. Пройди по таблице соответствия и навесь .uza-* классы на
соответствующие существующие блоки (бейджи, аватары, таблицы, тосты, степперы, кольца,
пустые состояния, переключатели и т.д.). DOM-структуру не меняй — только class. Эталоны —
preview/elements/*.html.
```

### Шаг 3 — Карточка задачи и модалка → `REDESIGN-CHANGESET.md`
`BoardKanban.vue` (фикс тройного DirectionBadge + боковая полоска + полные слова приоритета
+ аватар + список задач у проекта) и `TaskProjectEditor.vue` (степпер статусов, плашка
прогресса, сайдбар).

```
Прочитай REDESIGN-CHANGESET.md и примени разделы по BoardKanban.vue и TaskProjectEditor.vue.
Сохрани существующие поля/пропсы/логику — меняется только визуальная верстка. Покажи diff.
```

### Шаг 4 (опц.) — Идеи-предложения → `PROPOSALS-CHANGESET.md`
16 предложений (alert-KPI, секторные tints, контекстный топбар и т.д.) — применять
выборочно, по согласованию.

## Глобальные правила (для всех шагов)
- **Структуру/иерархию DOM и API компонентов не менять** — только визуальный слой.
- **Никаких `border-left`-акцентов** — точка/бейдж/боковая или верхняя вставная полоска.
- **Полные слова** в подписях статусов, без сокращений.
- **Секторные цвета** едины (mining/oilgas/chem/transport/energy).
- Эталон любого элемента — `preview/elements/*.html`; собранный экран — `preview/screens/company-card.html`.
- После каждого шага — `npm run lint` + сборка зелёные, показать diff.

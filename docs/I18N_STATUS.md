## 2. Как устроено (нужно понимать перед продолжением)

### 2.1. Ключ — это русская строка

```ts
t("Сохранить")            // → "Saqlash" / "Сақлаш" / "Save" / "Сохранить"
t("Строк: {n}", { n: 5 }) // плейсхолдеры переживают перевод
```

Нет перевода в словаре → показывается русский текст. **Поэтому недомигрированный
экран остаётся полностью рабочим**, а не пустым. Миграцию можно останавливать на
любом проценте готовности.

### 2.2. Узбекская кириллица не пишется руками

Словари ведутся ТОЛЬКО в латинице. Кириллица генерируется транслитерацией
(`frontend/src/locale/translit.ts`, зеркало на бэке `backend/app/core/i18n.py`):

- диграфы `sh→ш`, `ch→ч`, `ya→я`, `yo→ё`, `yu→ю`, `ye→е`;
- апострофные `oʻ→ў`, `gʻ→ғ`; остаточный апостроф → `ъ`;
- `e` в начале слова → `э`; `q→қ`, `h→ҳ`, `x→х`, `j→ж`;
- заимствования `-tsiya→-ция`, `-tsion→-цион`;
- акронимы (KPI, IFRS, FY) и римские I/V/X не транслитерируются.

В словарь `cyr` попадают **только исключения** — слова, где транслит даёт неверную
форму: «ь» в заимствованиях (фильтр, портфель, месяцы), «ц», капс-фразы.

**Гоча:** ALL-CAPS узбекские фразы попадают под защиту акронимов и НЕ
транслитерируются — для капс-заголовков всегда нужен `cyr`-override.

### 2.3. Где что лежит

```
frontend/src/locale/
  i18n.ts          ядро t(), авто-обнаружение словарей (import.meta.glob)
  translit.ts      латиница → кириллица
  locales.ts       реестр 4 локалей + Intl-коды
  dict/*.ts        словари по модулям: export const uz / en / cyr
frontend/src/composables/useI18n.ts   const { t } = useI18n()
frontend/src/components/LangSwitcher.vue  переключатель (подвал сайдбара)
frontend/scripts/i18n-residual.mjs    скан остаточной кириллицы

backend/app/core/i18n.py       зеркальное ядро tr() + та же транслитерация
backend/app/locale_dict/*.py   словари: UZ / EN / CYR
```

### 2.4. Как язык доезжает до бэкенда

- фронт шлёт заголовок `X-UI-Locale` на каждом запросе (`api/client.ts`);
- `users.ui_locale` в БД — для офлайн-каналов (письма, Telegram, дайджесты),
  где заголовка нет; синхронизируется при переключении языка;
- при входе на новом устройстве применяется язык из профиля.

## 5. Как продолжать

### 5.1. Готовый инструмент

Воркфлоу уже написан и лежит в сессии — его можно перезапустить с кешем:

```
scriptPath: .claude/.../workflows/scripts/i18n-frontend-migration-wf_4c5bb089-e82.js
resumeFromRunId: wf_d68d19db-cad
```

Завершённые модули отдаются из кеша мгновенно, работают только оставшиеся.
Внутри уже зашиты правила и уроки первых двух прогонов.

### 5.2. Правила для агента (если делать заново)

1. Обёртывать ВСЁ видимое: текстовые узлы, `title`, `placeholder`, `aria-label`,
   подписи табов и колонок, тексты тостов и подтверждений, пустые состояния.
2. Динамика — ТОЛЬКО плейсхолдерами: `t("Сохранено: {n}", { n })`.
   Никогда не склеивать переведённые куски конкатенацией.
3. **Реактивность:** модульные константы вычисляются один раз, `t()` внутри них
   не обновится при смене языка. Массивы вида `const TABS = [{ label: "Обзор" }]`
   оставлять русскими, а переводить в шаблоне: `{{ t(tab.label) }}`.
   Внутри `computed()` — можно.
4. НЕ переводить: комментарии, `console.*`, ключи API, пути маршрутов, CSS,
   названия компаний и людей, введённые пользователями данные.
5. Строки, по которым код СРАВНИВАЕТСЯ с данными бэкенда
   (`status === "В работе"`), не трогать — переводить только вывод.
6. **Не объявлять локальную переменную с именем `t`** — затенит функцию перевода.

## 6. Три дефекта, которые уже стоили времени — не повторять

1. **`t()` в дефолте `defineProps`** роняет сборку целиком: дефолты хойстятся вне
   `setup()`. Строки-дефолты хранить по-русски, переводить в точке отображения.
2. **Локальная `const t = ...`** затеняет функцию перевода. Два случая поймал
   `vue-tsc` как «expression is not callable», но если локальная переменная типа
   `any` — компилятор промолчит, сломается в рантайме.
3. **Словарь-сирота:** каждая строка в `t()` должна иметь запись в словаре, иначе
   на других языках останется русский. Проверять парность uz/en.

## 7. Что НЕ сделано и требует решения

- **Бэкенд-строки не переведены.** Ядро `tr()` и словарь `common.py` готовы,
  но сообщения об ошибках, шаблоны уведомлений, письма и Telegram по-прежнему
  отдаются по-русски. Требуется отдельный проход по `app/api/routes/*` и
  `app/services/notifications*`.
- **ИИ-ассистент отвечает по-русски** независимо от языка интерфейса. Нужно
  передавать локаль в системный промпт (`ai_context.py`).
- **Системные каталоги в БД** (статусы задач, метки БП, названия направлений)
  хранятся по-русски и не переводятся. Решение владельца: это данные или
  интерфейс — от этого зависит, добавлять ли `name_uz` / `name_en` в таблицы.
- **Контент не переводится принципиально** (решение владельца 29.07.2026):
  названия компаний, имена людей, введённые пользователями задачи, KPI,
  комментарии — остаются как введены на любом языке интерфейса.
